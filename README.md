# 🏨 Conserje - Gestión de Turistas en Cabañas

Una aplicación web para la gestión integral de reservas y hospedaje de turistas en cabañas.

## ✨ Características Principales

✅ **Reservar cabañas** - Los turistas pueden reservar cabañas disponibles
✅ **Gestión de Check-in** - Control de entrada de turistas
✅ **Disponibilidad** - Visualiza en tiempo real qué cabañas están disponibles
✅ **Interfaz amigable** - Diseño intuitivo para Android

## 📱 Cómo Probar la App

### Requisitos
- Navegador Chrome (recomendado)
- Windows

### Pasos para usar:

1. **Descargar el proyecto:**
   ```bash
   git clone https://github.com/jorgealegrectes-dotcom/conserje.git
   ```

2. **Abrir la app:**
   - Ve a la carpeta descargada
   - Abre el archivo `conserje-empedrado (1).html` con Chrome
   - ¡Listo! La app está funcionando
