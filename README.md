# 🏨 Conserje - Gestión de Turistas en Cabañas

Una aplicación web moderna y fácil de usar para gestionar reservas y hospedaje de turistas en cabañas. Perfecta para pequeños complejos turísticos, hospedajes y casas de descanso.

## ✨ Características Principales

### ✅ Funcionalidades Implementadas

- 🏠 **Visualizar Cabañas** - Ver todas las cabañas disponibles con detalles completos
- 📅 **Sistema de Reservas** - Reservar cabañas con datos del turista y fechas específicas
- ✔️ **Gestión de Check-in** - Registrar entrada de turistas automáticamente
- 📊 **Control de Disponibilidad** - Visualizar qué cabañas están libres u ocupadas
- 🎨 **Interfaz Intuitiva** - Diseño moderno y fácil de usar
- 📱 **Responsive** - Se adapta a diferentes tamaños de pantalla

### ⏳ Funcionalidades En Desarrollo

- 💾 **Persistencia de Datos** - Base de datos (próximamente)

## 📸 Pantallas de la App

### 🏠 Cabañas
- Lista visual de todas las cabañas
- Información: nombre, capacidad, precio
- Botón para reservar

### 📅 Reservas
- Listado de todas las reservas
- Detalles del turista
- Estado de la reserva
- Información de check-in

### ✔️ Check-in
- Selecciona una reserva
- Registra entrada del turista
- Se guarda hora y fecha automáticamente

### 📊 Disponibilidad
- Vista rápida de ocupación
- Cabañas libres (verde)
- Cabañas ocupadas (rojo)
