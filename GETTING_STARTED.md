# 🚀 Cómo Ejecutar Conserje - Guía Rápida

¡Bienvenido! Aquí te mostramos exactamente cómo descargar y usar la app Conserje.

## ⬇️ Paso 1: Descargar los Archivos

### Opción A: Descargar como ZIP (MÁS FÁCIL)
1. Ve a: https://github.com/jorgealegrectes-dotcom/conserje
2. Haz clic en el botón verde **"Code"**
3. Selecciona **"Download ZIP"**
4. Se descarga una carpeta comprimida
5. Descomprime la carpeta en tu computadora

### Opción B: Usar Git (Si tienes Git instalado)
```bash
git clone https://github.com/jorgealegrectes-dotcom/conserje.git
cd conserje
```

---

## 🎯 Paso 2: Abrir la App

### Windows:
1. Ve a la carpeta descargada
2. Busca el archivo: `conserje-empedrado (1).html`
3. Haz clic derecho sobre el archivo
4. Selecciona: **"Abrir con"** → **"Google Chrome"** (o tu navegador)
5. ¡Listo! La app se abrirá en tu navegador

### Mac:
1. Ve a la carpeta descargada
2. Busca el archivo: `conserje-empedrado (1).html`
3. Haz clic derecho → **"Abrir con"** → **"Chrome"**
4. ¡Listo!

### Linux:
```bash
# Navega a la carpeta
cd conserje

# Abre el archivo con Chrome
google-chrome conserje-empedrado\ \(1\).html

# O con Firefox
firefox conserje-empedrado\ \(1\).html
```

---

## ✨ Paso 3: Usar la App

Una vez abierta, verás la interfaz con 4 secciones principales:

### 🏠 **Sección: Cabañas**
- Ves todas las cabañas disponibles
- Cada una muestra: nombre, capacidad, precio, descripción
- Haz clic en una cabaña para reservarla
- Si está ocupada, no podrás hacer clic

### 📅 **Sección: Mis Reservas**
- Ver todas tus reservas creadas
- Ver detalles: fechas, turista, estado
- Ver si ya tiene check-in registrado

### ✔️ **Sección: Check-in**
- Selecciona una reserva de la lista desplegable
- Haz clic en "Registrar Check-in"
- Se registra automáticamente la fecha y hora

### 📊 **Sección: Disponibilidad**
- Vista rápida de todas las cabañas
- Verde = Libre
- Roja = Ocupada

## 🐛 ¿Algo no funciona?

### Soluciones Comunes:

**❌ "No puedo abrir el archivo"**
- Asegúrate de usar Chrome
- Intenta hacer clic derecho → "Abrir con" → Chrome

**❌ "El formulario no se abre"**
- Recarga la página (F5)
- Intenta en Chrome

**❌ "Los datos no se guardan"**
- Los datos se guardan en la sesión actual
- Si cierras y abres la página, se pierden
- (Próximamente habrá persistencia)

**❌ "Tengo otro error"**
- Ve a: https://github.com/jorgealegrectes-dotcom/conserje/issues
- Haz clic en "New Issue"
- Describe qué pasó
- ¡Nos ayudarás a mejorar!
